# 매장 판매 코칭 앱

사원이 판매 대화를 녹음해 올리면 AI가 행사 교육자료 기준으로 코칭하고, 사원이 고른 1건을 매니저가 평가하는 앱입니다.

- 주소: `https://aplus1013-cpu.github.io/coach/` (main 브랜치에 병합하면 GitHub Pages에 반영)
- 기존 `index.html`(구글 시트 조회)과는 별개이며, 기존 페이지는 건드리지 않습니다.

## 구성

| 부분 | 위치 | 설명 |
|---|---|---|
| 앱 화면 | `index.html`, `app/` | 빌드 없는 정적 웹앱(PWA). 휴대폰 홈 화면에 설치 가능 |
| 서버 DB·권한 | `supabase/migrations/` | Supabase 프로젝트 `sales-coach`(서울). 역할별 권한(RLS) |
| 서버 함수 | `supabase/functions/` | 계정 관리, 음성 인식(CLOVA), AI 평가·체크리스트(Claude) |
| 외부 라이브러리 | `vendor/` | supabase-js, SheetJS(엑셀), ffmpeg.wasm(음성 추출·압축) |
| 자동 테스트 | `tests/` | DB 권한 테스트 + 앱 전체 흐름 테스트(실제 서버 없이 로컬에서) |

## 처음 운영 준비

1. **서버 키 넣기**: Supabase 대시보드 → Edge Functions → Secrets
   - `ANTHROPIC_API_KEY`: Claude API 키
   - `CLOVA_INVOKE_URL`, `CLOVA_SECRET_KEY`: 네이버 클라우드 CLOVA Speech 도메인의 Invoke URL과 Secret Key
2. **첫 관리자 만들기**: 앱 로그인 화면 → ‘처음 설정’ → 전달받은 설정 코드 입력. 관리자가 생기면 코드는 사라집니다.
3. **(권장) 가입 막기**: Supabase → Authentication → Sign In / Providers에서 ‘Allow new users to sign up’ 끄기. 계정은 앱의 관리자·매니저 화면에서만 만듭니다.
4. **점검**: 앱 메뉴 → ‘시스템 점검’에서 모든 항목이 ✓인지 확인합니다.

## 계정

- 관리자·매니저: 이메일 + 비밀번호. 관리자가 ‘계정’ 화면에서 한 명씩 또는 엑셀로 등록하고 초기 비밀번호를 전달합니다.
- 사원: 사번 + 비밀번호. 관리자(전 매장) 또는 매니저(자기 매장)가 등록합니다. 엑셀 일괄 등록을 지원합니다.
- 처음 로그인하면 누구나 비밀번호를 바꿔야 합니다. 잊으면 매니저·관리자가 초기화합니다.

## 노트북 일괄 평가(관리자 ‘일괄 평가’ 탭)

사원에게 받은 녹음을 노트북 폴더에 모아 두고 한 번에 평가합니다.

1. ‘폴더 선택’을 누르거나 폴더를 화면에 끌어다 놓습니다.
2. 파일 이름이나 폴더 이름에 들어 있는 **사원 이름**과 **행사 품목 이름**으로 자동 연결합니다(예: `홍길동_갤럭시S26_0915.m4a`, `갤럭시S26/홍길동.mp4`). 행사가 없으면 ‘기본 행사’를 고릅니다.
3. 명단에 없는 이름은 ‘명단에 없는 사원 추가’에서 **이름만** 등록합니다. 로그인 계정(사번)은 나중에 만듭니다.
4. ‘평가 시작’을 누르면 하나씩 압축해 올리고 AI 분석 결과(점수·준수율)가 표에 채워집니다. ‘결과 보기·평가’에서 관리자 점수와 코멘트를 더하고, ‘결과 엑셀로 받기’로 내려받습니다.
5. 전에 올린 파일(같은 이름·크기)은 자동으로 빼 둡니다.

## 저장 공간 관리(무료 플랜 1GB)

- 녹음은 휴대폰 안에서 음성 인식용으로 압축(모노 16kHz)한 뒤 올립니다. 동영상은 음성만 추출합니다. 서버 파일 한도는 50MB입니다.
- 제출하지 않은 연습 녹음은 7일 뒤 자동으로 지워지고 녹취·AI 결과는 남습니다. 제출·대리 업로드·우수 사례 녹음은 보관됩니다.

## 테스트 실행(개발용)

```bash
cd coach/tests
npm i @electric-sql/pglite xlsx @ffmpeg/core@0.12.10 playwright   # 한 번만
DENO=$(which deno) PLAYWRIGHT=playwright ./run-all.sh
```

- DB 권한 테스트: 실제 마이그레이션 SQL을 메모리 Postgres(PGlite)에 적용하고 역할별로 볼 수 있는/없는 데이터를 확인합니다.
- 앱 전체 흐름 테스트: 흉내 서버 + 실제 서버 함수 코드(Deno) + 실제 앱 화면(Chromium)으로 관리자·매니저·사원 흐름 31단계를 확인합니다. CLOVA와 Claude는 가짜 응답을 쓰되, 요청 형식(모델, 화자 분리 등)은 검사합니다.
